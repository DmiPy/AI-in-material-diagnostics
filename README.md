# AI in Material Diagnostics – Semester Project

## How to use this repository

### 1. Clone the repository to your computer

> If you don’t have a GitHub account, no problem – you can still clone the repo.

Using HTTPS (no login needed for public repo):
```bash
git clone https://github.com/DmiPy/AI-in-material-diagnostics.git
```
If you don't have a GitHub account, or Git installed:

- Go to the GitHub repo page

- Click the green Code button → Download ZIP

- Extract the ZIP file to your computer
    
### 2. Create your own Branch
> Each student should work in their own branch.
Use the following naming format:
```bash
assignment/<your_initials>
```

For example if you are on main branch:
```bash
git checkout -b assignment/dk
```
Instead of dk should be your initials

### 3. Work on your solution

There is a starter script in main.py which you can:

- Use and continue editing

- Or replace with your own implementation

You are free to structure your files as you like within your branch.
